# Legacy Review Archive

Files in this directory are immutable historical evidence from Harness V2.
Their Candidate and verdict claims remain historical facts, but they are not
active runtime state and define no current execution semantics.

Harness V3 stores reservations, reviewer runtime, findings, verdicts, parking,
and PASS state in the Epoch GitHub PR. Normal V3 execution must not create or
modify files here. See
[`docs/agent/HARNESS.md`](../../agent/HARNESS.md).
