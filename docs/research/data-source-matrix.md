# Bangumi 数据源矩阵

> PR-7A 研究交付物。TTL 是候选产品默认值，需在实现前按站点行为与条款验证；它不是 Bangumi 的官方 SLA。

## 统一等级

- Reliability：`A` = 官方稳定契约或本地固定 schema；`B` = 官方数据的确定性派生；`C` = 公开 HTML 可观察但页面/覆盖会变；`D` = 未验证/不应作为默认依赖。
- Priority：`P0` = PR-7B/基础查询必须；`P1` = 高价值后续；`P2` = 研究或可选 provider。
- Authenticated 写入不表示本矩阵建议自动写入；只说明该数据或操作的授权边界。

## Source priority rules

1. 结构化实体、关系、收藏和进度：官方 v0 优先；HTML 只用于产品对照或补充网页展示字段。
2. 标签与概念：API 字段先于网页词表；网页词表用于 resolver evidence，不自动变成同义词。
3. 统计/社区：如果只存在 HTML，结果必须保留 provider/source/freshness/coverage；没有历史快照不计算 trend。
4. 图片：官方/公开图片 URL 可以进入受 SSRF 约束的 AssetResolver；源格式、响应类型和处理结果需可诊断。
5. 认证数据：只在当前授权 scope 内读取，禁止进入公共缓存、匿名结果或跨用户 renderer artifact。

## 推荐初始缓存策略

这是产品设计默认值，不是实现授权：

- subject/person/character/relations：1–12 小时，按实体和 source operation 分 key。
- calendar/airing：平时 30 分钟，放送临近可降到 5 分钟。
- public collections：1–6 小时；current user collection/episode progress 不进入共享 cache。
- community HTML：5–30 分钟，严格按 provider allowlist；失败不把空页面写成成功快照。
- historical snapshot：保存 parser version、filter、retrievedAt、coverage、HTTP status 和缺页信息。
