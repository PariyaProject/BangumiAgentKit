# G01: 2026 年 7 月后宫动画 live probe（源码 commit `18a1537`）

**观测。** 2026-10-02 20:59:52 UTC（2026-10-03 05:59:52 JST）的只读 ToolRegistry 调用使用 `media=anime, year=2026, month=7, concepts=[后宫], resultMode=all, limit=100, explain=full`。结果为 `state=ok`、15 行；每行均含精确的 `后宫` 标签，日期均落在半开区间 `[2026-07-01, 2026-08-01)`。覆盖字段为 `state=complete`、scanned/matched/returned 均为 15、pagesScanned=1、upstreamExhausted=true、totalKind=estimated，并带 `EXPERIMENTAL_SOURCE` 警告。这是当前源码下的一次直接 ToolRegistry 结果，不是 Agent 编排、MCP 展示或 QQ/TIM 客户端证据。场景目录把这类问题列为 G01，并要求月份/日期、动画类型和概念证据。[G01 场景](https://github.com/PariyaProject/BangumiAgentKit/blob/18a15373ca5b7c6ddd41016863277d385d8081d5/docs/research/user-scenario-catalog.md#L15)

**当前代码语义。** `bangumi.query_subjects` 声明为无认证、只读工具；`anime` 映射到上游类型 2，年月转换成起始日含、下月首日不含的日期范围。`后宫` 在本地概念词表中精确映射到普通 `tag`，不扩展同义词；由于查询有概念条件，编译路径使用官方 `searchSubjects`，把类型、`air_date` 范围和 `tag` 作为 AND 条件发送。[工具定义](https://github.com/PariyaProject/BangumiAgentKit/blob/18a15373ca5b7c6ddd41016863277d385d8081d5/packages/tools/src/definitions/discovery-tools.ts#L112-L126) [类型映射](https://github.com/PariyaProject/BangumiAgentKit/blob/18a15373ca5b7c6ddd41016863277d385d8081d5/packages/discovery/src/compiler.ts#L18-L24) [年月规范化](https://github.com/PariyaProject/BangumiAgentKit/blob/18a15373ca5b7c6ddd41016863277d385d8081d5/packages/discovery/src/query.ts#L96-L103) [概念映射](https://github.com/PariyaProject/BangumiAgentKit/blob/18a15373ca5b7c6ddd41016863277d385d8081d5/packages/discovery/src/concept-resolver.ts#L12-L20) [条件与分页请求编译](https://github.com/PariyaProject/BangumiAgentKit/blob/18a15373ca5b7c6ddd41016863277d385d8081d5/packages/discovery/src/compiler.ts#L85-L119) [搜索路径选择](https://github.com/PariyaProject/BangumiAgentKit/blob/18a15373ca5b7c6ddd41016863277d385d8081d5/packages/discovery/src/compiler.ts#L135-L143)

本地官方 OpenAPI 将 `POST /v0/search/subjects` 标为实验性；不同筛选条件为 AND、类型数组内部为 OR，并定义 `tag` 与 `air_date` 日期比较语法。provider 将本查询的筛选传给该操作、把 total 标为 estimated，并产生 `EXPERIMENTAL_SOURCE` 警告。[官方 OpenAPI](https://github.com/PariyaProject/BangumiAgentKit/blob/18a15373ca5b7c6ddd41016863277d385d8081d5/openapi/upstream/v0.yaml#L15-L33) [筛选 schema](https://github.com/PariyaProject/BangumiAgentKit/blob/18a15373ca5b7c6ddd41016863277d385d8081d5/openapi/upstream/v0.yaml#L73-L105) [provider 映射与警告](https://github.com/PariyaProject/BangumiAgentKit/blob/18a15373ca5b7c6ddd41016863277d385d8081d5/packages/provider-core/src/providers.ts#L1365-L1400)

`resultMode=all` 表示在受限预算内尝试完整读取；本次 `limit=100` 被限制为每个上游页最多 50 条；`all` 会按偏移继续分页，输出上限是默认预算 100。引擎会在上游耗尽且没有预算、截断或未解决 hydration 时报告 complete；search 的 estimated total 和短页耗尽仅支持“当前查询窗口已读完”，不证明 Bangumi 全库枚举完整。代码的解释字段也明确限定为当前启用的官方源结果集。[all 模式限制与 estimated total](https://github.com/PariyaProject/BangumiAgentKit/blob/18a15373ca5b7c6ddd41016863277d385d8081d5/packages/discovery/src/compiler.ts#L228-L254) [默认预算](https://github.com/PariyaProject/BangumiAgentKit/blob/18a15373ca5b7c6ddd41016863277d385d8081d5/packages/discovery/src/query.ts#L15-L31) [分页/覆盖计算](https://github.com/PariyaProject/BangumiAgentKit/blob/18a15373ca5b7c6ddd41016863277d385d8081d5/packages/discovery/src/engine.ts#L585-L635) [覆盖范围说明](https://github.com/PariyaProject/BangumiAgentKit/blob/18a15373ca5b7c6ddd41016863277d385d8081d5/packages/discovery/src/engine.ts#L714-L727)

**边界与研究笔记。** `month=7` 是 2026 年 7 月的日历月份，不是整个 2026 夏季季度；若“七月番”意指夏季番，应改用 `season=2026-summer`，其日期范围是 7 月至 10 月。另一个契约细节是 OpenAPI 将 keyword 标为必填，而当前 wrapper 在未提供 keyword 时发送空字符串；这次成功结果证明该调用当时可用，实验性 API 仍可能改变。[季节月份](https://github.com/PariyaProject/BangumiAgentKit/blob/18a15373ca5b7c6ddd41016863277d385d8081d5/packages/discovery/src/query.ts#L33-L38) [季节日期范围](https://github.com/PariyaProject/BangumiAgentKit/blob/18a15373ca5b7c6ddd41016863277d385d8081d5/packages/discovery/src/query.ts#L105-L118) [OpenAPI keyword 要求](https://github.com/PariyaProject/BangumiAgentKit/blob/18a15373ca5b7c6ddd41016863277d385d8081d5/openapi/upstream/v0.yaml#L47-L56) [空 keyword 默认值](https://github.com/PariyaProject/BangumiAgentKit/blob/18a15373ca5b7c6ddd41016863277d385d8081d5/packages/discovery/src/query.ts#L142-L145)

既有设计笔记要求概念先精确匹配、避免静默扩展同义词；场景目录中的 G01 缺口也正是日期与标签筛选。现有官方 API 能力笔记描述的是较窄的 `bangumi.search_subjects` 工具，不能据此否定当前 `bangumi.query_subjects` 的能力。[概念解析设计](https://github.com/PariyaProject/BangumiAgentKit/blob/18a15373ca5b7c6ddd41016863277d385d8081d5/docs/research/query-model-design.md#L151-L187) [官方 API 与旧 search 工具说明](https://github.com/PariyaProject/BangumiAgentKit/blob/18a15373ca5b7c6ddd41016863277d385d8081d5/docs/research/official-api-capabilities.md#L41-L46) [旧工具语义范围](https://github.com/PariyaProject/BangumiAgentKit/blob/18a15373ca5b7c6ddd41016863277d385d8081d5/docs/research/official-api-capabilities.md#L134-L143)
