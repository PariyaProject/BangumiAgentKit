It returns per-subject `stats.ratingTotal` values and a `metrics` entry with key `ratingTotal`, ordered values `[A, B]`, and delta `B − A`, rounded to integer precision. ## Coverage limits

- The result is a current read with source evidence and retrieval timestamps, not a historical change series or a population sample. The tool performs subtraction; it defines no statistical test, confidence interval, sampling model, or significance decision. A numeric gap alone cannot establish statistical significance or whether it is unusual among comparable subjects.
- Since the request contains no caller threshold or use-case, the tool can report the direction and size of the gap but cannot decide whether it is practically “large enough.” That judgment needs an explicit caller criterion and context. The absence of such a criterion is not a zero threshold.
- The OpenAPI's integer type is the source contract, but the local metric path checks finiteness when mapping and subtracting values; it does not apply a documented count range or practical threshold. Separately, derived-statistics validation expects a non-negative integer. [Metric input mapping](https://github.com/PariyaProject/BangumiAgentKit/blob/aa10199b2e193252b44732220e94d67c06feabff/packages/tools/src/subject-comparison.ts#L136-L138) · [Derived-statistics validation](https://github.com/PariyaProject/BangumiAgentKit/blob/aa10199b2e193252b44732220e94d67c06feabff/packages/tools/src/subject-stats-intelligence.ts#L179-L198)
